# Kasa

Apartment rental web application built with React.

**Live demo:** [kasa-apartment-rental.netlify.app](https://kasa-apartment-rental.netlify.app)
**GitHub repository:** https://github.com/JacquelineAndressa/kasa-apartment-rental.git

## About

4th project of the OpenClassrooms Front-End Web Developer program. The goal was to develop the frontend of a property rental application using React, React Router, and Sass.

## Installation

```bash
git clone https://github.com/JacquelineAndressa/kasa-apartment-rental.git
cd kasa-apartment-rental
npm install
npm run dev
```

## Tech Stack

React · React Router · Vite · Sass
